# Работа с репозиторием

- Основная рабочая ветка — `base`. Дальнейшие изменения коммитьте и отправляйте непосредственно в неё, если пользователь не попросил иначе.
- Не создавайте и не восстанавливайте ветку `feat/mono-digital-studio`: её изменения объединены в `base`.
- Перед публикацией проверяйте, что исходный коммит совпадает с `origin/base`. Сборка и публикация должны соответствовать этому коммиту.
- Для изменений приложения запускайте `npm run test:i18n` и `npm run build`.
- Сохраняйте идентификатор и настройки доступа существующего сайта в `.openai/hosting.json`. Sites использует собственное служебное зеркало исходников; рабочим источником остаётся GitHub-ветка `base`.
- Поддерживайте русскую и английскую версии интерфейса. Документацию ведите на русском.
