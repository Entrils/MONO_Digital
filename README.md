# MONO® Digital Studio

Одностраничный сайт концептуальной digital-студии: сдержанная типографика, портфолио, описание подхода, услуги и форма брифа. Русская и английская версии переключаются без перезагрузки.

## Посмотреть сайт

[Русская версия](https://mono-digital-studio-entrils.limitlessbeam.chatgpt.site/?lang=ru) · [English](https://mono-digital-studio-entrils.limitlessbeam.chatgpt.site/?lang=en).

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev       # разработка
npm run test:i18n # DOM-проверки локализации
npm run build     # сборка в dist/
npm run preview   # просмотр сборки
```

**Стек:** React 19, Vite, JavaScript, CSS Modules, GSAP + ScrollTrigger, Lenis, Lucide React. Tailwind не используется.

## Локализация

Переключатель **EN / RU** доступен в шапке, в том числе при открытом мобильном меню. Приоритет языка: параметр `?lang=ru` или `?lang=en` → сохранённый выбор → поддерживаемый язык браузера → английский. Выбор хранится в `localStorage` под ключом `mono-language`; при недоступном хранилище сайт продолжает работать.

Переведены интерфейс, описания проектов и услуг, форма, сообщения валидации, подписи для скринридеров и метаданные. Переключение обновляет атрибут `lang`, заголовок страницы и описание, сохраняет заполненный бриф и выбранные значения. Бюджеты отображаются в долларах США с форматированием выбранного языка; конвертации валют нет. Названия MONO, AETHER, FORM/01, NOVA, OBJECTS и авторские изображения проектов сохраняют оригинальное написание.

## Взаимодействия и доступность

Кейсы открываются в нативном диалоге с закрытием по Escape. Мобильное меню поддерживает клавиатуру и удержание фокуса; услуги раскрываются по нажатию, с клавиатуры по нажатию на компьютере. Переключатель языков сообщает выбранное состояние скринридеру.

Форма проверяет обязательные поля и адрес электронной почты, затем создаёт ссылку `mailto:` с заполненным брифом. Отправка выполняется пользователем в почтовом приложении; серверной отправки и хранения нет. Контакты предоставлены владельцем: `mono_art_design@gmail.com`, Telegram `@MonoDesign`. Москва, работа очно и удалённо. Имена четырёх участников сгенерированы по запросу и явно обозначены как концептуальный состав; проекты также остаются авторскими концептами.

Настройка `prefers-reduced-motion` отключает плавный скролл и анимации появления. Изображения загружаются адаптивно. Декоративная 3D-сцена не используется и не входит в сборку страницы.

## Проверки и публикация

`npm run build` проверяет production-сборку. `npm run test:i18n` проверяет приоритет выбора языка, сохранение состояния формы, локализованные метаданные и ошибки, кейсы, навигацию с клавиатуры и работу без доступа к хранилищу браузера. Они не проверяют реальную геометрию страницы . Визуальная проверка размеров 320, 375, 768, 1024, 1440 и 1920 px требует браузера; в текущей сессии инструмент управления браузером недоступен.

Содержимое `dist/` можно разместить на любом статическом хостинге. Файл `.openai/hosting.json` связывает исходники с приватной публикацией Sites. Рабочая ветка и источник публикаций — `base`. Для деплоя используется точный коммит этой ветки и собранный из него `dist/`; Sites хранит копию исходников в своём служебном репозитории. Дальнейшие изменения выполняются непосредственно в `base`.

Изображения портфолио — специально созданные с помощью генерации концептуальные визуализации, а не фотографии выполненных клиентских заказов. Для каждого проекта подготовлена отдельная арт-дирекция; адаптивные WebP-версии загружаются локально с `srcSet`, `sizes` и ленивой загрузкой.

Текущая редакция делает акцент на проектах и содержании: убраны прелоадер, бегущая строка, декоративная 3D-сцена, кастомный курсор и повторяющиеся манифесты. Кейсы описывают задачу концепта, визуальное решение и предложенные направления работы; реальные клиенты и результаты не выдумываются.

## Развитие кейсов

AETHER показывает знак, палитру, типографику, редакционный разворот и экранные макеты. OBJECTS содержит интерактивный прототип каталога: фильтры, раскрытие сведений о предмете и адаптивную сетку, без имитации покупки. Обе разработки доступны из карточек портфолио. Фактические контакты и предлагаемый состав команды вынесены в `src/studio.js`.
